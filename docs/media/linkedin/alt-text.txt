Architecture diagram of an iMessage assistant. A user asks for a PR briefing in five minutes. Sendblue receives the message and delivers it to a FastAPI and Uvicorn API, which verifies the webhook and saves a job in Supabase PostgreSQL. A CrewAI worker reads and writes jobs, saved notes, history, and schedules in Supabase, calls OpenAI gpt-6.1-sol, and sends replies through Sendblue back to iMessage. Sendblue also provides typing bubbles and read receipts. Each sender has separate history, notes, and account connections. A Python scheduler queues due reminders from saved schedules. Optional Gmail and GitHub tools are accessed through Composio MCP. Browserbase and Playwright provide remote browser sessions for public-page research. Tool logos appear beside their components.
